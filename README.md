### [Game Glitch Investigator — game debugging and strategy coach](https://github.com/kyle-m-mitchell/game-glitch-investigator)

Extended a CodePath Streamlit game by fixing state and hint logic, separating game rules into testable Python functions, adding automated tests, and building a Strategy Coach that shows the remaining search interval and a suggested next guess. The repository documents how I reviewed AI-generated suggestions and corrected mistakes during development. The Strategy Coach uses deterministic game logic rather than a runtime AI model.

### [PawPal+ — pet-care scheduler](https://github.com/kyle-m-mitchell/pawpal-plus-pet-care-scheduler)

A CodePath project extension using Python classes to organize pets, recurring care tasks, and owner availability. It includes conflict handling, greedy rescheduling, an optional dynamic-programming scheduling strategy, and automated tests.

These projects document design choices, verification, and areas for further work.
